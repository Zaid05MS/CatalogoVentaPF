# Emotions GDL · Catálogo de Servicios

Proyecto final de Programación Web.

## Stack
- HTML5 + CSS3 + Bootstrap 5
- JavaScript (Fetch API)
- PHP (API REST)
- SQLite 3

## Estructura
```
proyecto_final_ax/
├── index.html
├── catalogo.html
├── admin.html
├── REAME.md
├── .gitignore
└── catalogo-servicios/
    ├── api/
    │   ├── db.php
    │   ├── listar.php
    │   ├── crear.php
    │   ├── actualizar.php
    │   └── eliminar.php
    ├── css/
    │   └── styles.css
    ├── js/
    │   └── servicios.js
    ├── db/
    │   └── catalogo.sqlite  ← se crea automático
    └── img/
```

## Cómo correr el proyecto

```bash
cd proyecto_final_ax
php -S localhost:8000
```
Abre: http://localhost:8000
